GuEarth 是一个仍在早期开发中的桌面数字地球，面向地理教学。它把真实影像和地形装进一个本地运行的 3D 地球，配合教学工具、主题模块和 AI 助手，让晨昏线、气压带、河流地貌这些"讲不动的"内容动起来。

## 你可以用 GuEarth 做什么

### 把地球当作讲台

- 在本地流畅浏览 3D 地球，自由切换 OSM、Mapbox、ArcGIS 等多种影像底图，并按需叠加地形；
- 输入地名即可定位飞行，也可以直接对地球拾取查询高程；
- 瓦片缓存在本机，讲过的区域下一次加载更快。

### 上课时随手标注、随手量

- 在地球上画点、线、面，量距离、量面积，写文字标注，重启后都还在；
- 内置配套人教版选择性必修一的主题模块：地球运动（晨昏线、太阳视运动、黄赤交角）、大气（气压带风带、热力环流、锋面气旋、台风）、地貌（板块边界、河流地貌、喀斯特等实景飞行）、海洋（厄尔尼诺与拉尼娜、水循环、洋流与潮汐）；
- 配套图表和剖面面板——昼长、正午太阳高度、海陆温度盐度剖面、真实地形高程剖面——随讲随看。

### 让 AI 助手陪你讲

- EOQ 智能体随聊天操作地球：飞行定位、查询地形、叠加图层、讲解地貌，都能由模型直接驱动；
- 支持DeepSeek、Qwen 等 OpenAI 兼容的模型服务，配置好 API Key 就能用；
- 模型的回答边生成边显示，讲到哪飞到哪。

## 本地优先

- GuEarth 不提供账号、同步或云服务器；标注、设置和 AI 配置都保存在当前电脑上；
- **地图影像、地形与地名数据来自你配置的地图服务提供商，聊天内容会发送到你配置的模型服务提供商**，这些数据由相应供应商处理；
- 应用发生错误或崩溃时，错误日志（含堆栈信息）会通过 Sentry 上传，用于定位和修复问题；除此之外，GuEarth 不会上传你的任何使用数据。
